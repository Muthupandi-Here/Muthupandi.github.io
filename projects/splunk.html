📊 Splunk Log Analysis Home Lab

Hands-on Security Information and Event Management (SIEM) project.

Project Overview

This project demonstrates how I installed Splunk Enterprise, added log data, performed searches using SPL (Search Processing Language), and analyzed security events in a home lab environment.

Project Objective

To understand how a SOC Analyst monitors, searches, and investigates system logs using Splunk SIEM.

Tools Used

  • Splunk Enterprise
  • Windows 11
  • VirtualBox
  • Web Browser

Lab Environment

Component Details
SIEM Tool Splunk Enterprise
Operating System Windows 11
Virtualization VirtualBox
Purpose Security Log Analysis

Skills Demonstrated

  • Log Analysis
  • SIEM Monitoring
  • SPL Searching
  • Alert Investigation

Installation Steps

  1. Downloaded Splunk Enterprise.
  2. Installed Splunk on Windows.
  3. Started the Splunk service.
  4. Logged into the Splunk Web interface.
  5. Added sample data or Windows Event Logs.
  6. Created indexes.
  7. Performed searches using SPL.
