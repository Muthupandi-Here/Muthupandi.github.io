📊 Splunk Log Analysis Home Lab

Hands-on Security Information and Event Management (SIEM) project.

Project Overview

This project demonstrates how I installed Splunk Enterprise, added log data, performed searches using SPL (Search Processing Language), and analyzed security events in a home lab environment.

Project Objective

To understand how a SOC Analyst monitors, searches, and investigates system logs using Splunk SIEM.

Tools Used

  • Splunk Enterprise
  • Windows 11
  • VirtualBox
  • Web Browser

Skills Demonstrated

  • Log Analysis
  • SIEM Monitoring
  • SPL Searching
  • Alert Investigation
